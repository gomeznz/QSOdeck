Setting up a macro keypad

  1. Plug the keypad into the computer you log on. It appears as an ordinary keyboard, with no driver.
  2. Using the maker's programming tool (usually Windows only), set each key to one of F13 to F24. Nothing else uses those, so they can never clash with typing. The keypad remembers them.
  3. Set each knob direction to its own key as well, such as Ctrl+F13 and Ctrl+F14. Avoid the volume setting; the computer keeps those for itself.
  4. Come back here, press "Map a key", press the key, and choose what it does.

The map is stored on the Pi and works on every QSODesk page and every device. Any spare keys on a normal keyboard can be mapped the same way.
